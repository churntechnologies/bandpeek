# BandPeek 0.1.0-beta.7

- **No more gap in the menu bar.** The ↓/↑ speeds used to reserve room for the
  widest possible value ("888.8 MB/s"), leaving empty space to their left. The
  item now fits the speeds shown. It widens at once when they grow and narrows
  only after they have stayed smaller for about 30 seconds, so neighbouring
  menu-bar items don't shift with every update.
- **A refreshed look.** The popup, main window and Settings use rounded,
  softly layered cards, more spacing and a clearer type hierarchy:
  - The popup is a little wider (340 pt) with rounder corners, separate
    Download/Upload tiles, a Today card with a download/upload bar, and roomier
    app rows with larger icons.
  - The main window shows live speeds as pills and puts the totals and the app
    table in their own cards, with a search field icon and lighter separators.
  - Settings groups its options in one card over a lightly blurred backdrop.
- No behaviour change beyond the menu-bar width: collection, history, updates
  and privacy are as in beta.6. Nothing new is sent anywhere.

See [beta.7 validation](../beta7-validation.md) for the checks that were run and
what was not covered. Apple Silicon/macOS 13+, validated on macOS 27.

An approved unnotarized build is ad-hoc signed, not Apple Developer ID signed or
notarized. If macOS blocks first launch and you choose to trust this beta, use
**System Settings → Privacy & Security → Open Anyway**, then confirm **Open**.
Existing beta.6 installs update to this build automatically within about six
hours, when BandPeek is quit and reopened, or via **Settings ▸ Updates**.
