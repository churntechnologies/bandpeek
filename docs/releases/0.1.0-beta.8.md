# BandPeek 0.1.0-beta.8

- **WebKit Networking, named after its app.** WebKit runs one Networking
  process for each app that shows web content, and macOS names each one after
  its app. BandPeek now shows that name, for example **Safari Networking** or
  **Mail Networking**, so a busy row tells you which app's web traffic it is.
  - It is still its own row, not added to the app's row, and its tooltip
    names the app it works for.
  - BandPeek never guesses: when macOS gives no such name, the row stays
    **WebKit Networking**.
  - Traffic recorded before this version stays under **WebKit Networking**.
    New traffic goes to the named rows. No database change.
- **Tighter menu bar.** The speeds now have 2 pt of padding on each side
  instead of 6 pt, so BandPeek sits about as close to its neighbours as other
  menu-bar text items. Icon only is unchanged.
- Retain everything from beta.7: the refreshed popup, main window and
  Settings, the menu-bar width that follows the speeds, the Updates row and
  live per-app speeds.

See [beta.8 validation](../beta8-validation.md) for the checks that were run
and what was not covered. Apple Silicon/macOS 13+, validated on macOS 27.

An approved unnotarized build is ad-hoc signed, not Apple Developer ID signed or
notarized. If macOS blocks first launch and you choose to trust this beta, use
**System Settings → Privacy & Security → Open Anyway**, then confirm **Open**.
Existing beta.7 installs update to this build automatically within about six
hours, when BandPeek is quit and reopened, or via **Settings ▸ Updates**.
