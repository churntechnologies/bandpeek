# BandPeek 0.1.0-beta.2 candidate

Locally validated basis for beta.2. No tag or release has been published.

- Live menu-bar rates now use 2-second collection and collector notifications.
  A sustained download rises/drops in about 3.7 seconds on the tested machine.
  Minute history aggregation and approximately once-per-minute SQLite writes remain.
- The popup retains one initialized WebView and hides on dismissal. Across 100
  opens, subsequent rendered-content latency was 43 ms median / 68 ms p95, with
  a 134 ms maximum. Focus-loss dismissal and one collector are preserved.
- Add opt-in sample diagnostics and reproducible sustained-download, popup
  latency, CPU/RSS, and repeated-instance validation harnesses.

See [the validation report](../beta2-validation.md) for diagnosis, measurements,
resource tradeoffs, unit conversion, source-counter limitations and reproduction.

Apple Silicon / macOS 13 or later; validated on macOS 27. Existing best-effort
socket accounting, shared-helper attribution, and short-lived-process limitations
remain. The updater's permanent key and verification, display modes, history,
settings, and Launch at Login code retain their existing policies. Retaining the
popup increases idle RSS in exchange for fast interaction.

Packaging/publication is a separate release step. The prior exact-tag beta.1
unnotarized release exception remains scoped to beta.1.
