# BandPeek 0.1.0-beta.4 candidate

Local candidate only. No tag or publication is authorized or performed.

- See which apps are using the network right now. A new **Now** tab in the main
  window lists each app's current download, upload and total speed and its share
  of the Mac's current total, with the same sorting and filter as the history
  ranges. The tab is remembered like the history ranges.
- The menu-bar popup adds a **Using now** section with the three busiest apps
  above "Top apps today". It keeps a fixed height, so the popup does not resize
  as apps start and stop.
- Speeds come from the existing two-second samples, grouped by the same identity
  as history rows: an app's helper processes count as the app. Each live update
  carries the 25 busiest apps. The list clears during collector gaps and
  discarded samples, like the total speed.
- Retain two-second sampling, minute history, the cached popup, topology
  recovery and the existing updater verification/install lifecycle.

See [beta.4 validation](../beta4-validation.md) for the measured checks and
reproduction. Speeds lag by about one sample. Traffic carried by shared macOS
helpers (for example Safari through WebKit Networking, App Store and system
downloads through `nsurlsessiond`) is shown under the helper. Existing macOS
best-effort socket accounting and short-lived-process limitations remain. Apple
Silicon/macOS 13+, validated on macOS 27.

An approved unnotarized build is ad-hoc signed, not Apple Developer ID signed or
notarized. If macOS blocks first launch and you choose to trust this beta, use
**System Settings → Privacy & Security → Open Anyway**, then confirm **Open**.

Publication remains subject to the existing exact-tag release policy. This task
does not authorize a tag, GitHub release, updater manifest publication, or install
over the user's application.
