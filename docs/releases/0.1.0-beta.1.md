# BandPeek 0.1.0-beta.1

This is a macOS beta for Apple Silicon, requiring macOS 13 or later. It has been tested on macOS 27 only.

**This beta is ad-hoc signed. It is not Apple Developer ID signed or notarized.** Developer ID signing and notarization are deferred to a later release. macOS may block the first launch because it cannot verify the developer or check notarization.

Download the DMG from this release, copy BandPeek.app to `/Applications` (or a user-owned Applications folder), and try opening it in Finder. If macOS blocks it and you choose to trust this beta, go to **System Settings → Privacy & Security → Open Anyway**, then confirm **Open**. See [Apple's instructions](https://support.apple.com/en-us/102445). Keep Gatekeeper enabled and retain quarantine protections.

The release includes the DMG, `BandPeek.app.tar.gz`, its `.sig`, `latest.json`, and `SHA256SUMS`. The updater archive is signed with BandPeek's permanent production updater key. The app and release workflow verify updater signatures against the embedded public key; this remains mandatory even though Apple notarization is deferred. Checksums detect damaged downloads and do not replace signature verification.

BandPeek shows per-app network estimates in the menu bar and stores usage history locally. Collection is best-effort; short-lived traffic may be missed. Windows and Linux are not implemented. The early unexplained process exit, macOS 27 child-fork diagnostic caveat, and pending human interface/accessibility/login checks are recorded in [beta validation](https://github.com/churntechnologies/bandpeek/blob/v0.1.0-beta.1/docs/beta-release-validation.md) and [manual checks](https://github.com/churntechnologies/bandpeek/blob/v0.1.0-beta.1/docs/manual-checks.md).
