# BandPeek 0.1.0-beta.9

- **The menu-bar gap, fixed properly.** BandPeek's menu-bar item keeps the
  width of its widest recent speed for about 30 seconds, so neighbouring items
  don't jump around. With everyday traffic a short burst arrives more often
  than that, so the item was usually wider than the speeds shown, and because
  the speeds were right-aligned all of that spare room sat on the left, next to
  the neighbouring item. beta.8's tighter padding couldn't fix that.
  - The speeds are now left-aligned. The arrows always sit 2 pt from the
    item's left edge, so the gap to the item on its left matches the gaps
    between other menu-bar items.
  - After a burst, the spare room sits on the right until the item narrows.
    Nothing shifts more often than before.
- Retain everything from beta.8: WebKit Networking rows named after their app
  (for example **Safari Networking**), the refreshed popup, main window and
  Settings, the Updates row and live per-app speeds.

See [beta.9 validation](../beta9-validation.md) for the checks that were run
and what was not covered. Apple Silicon/macOS 13+, validated on macOS 27.

An approved unnotarized build is ad-hoc signed, not Apple Developer ID signed or
notarized. If macOS blocks first launch and you choose to trust this beta, use
**System Settings → Privacy & Security → Open Anyway**, then confirm **Open**.
Existing beta.8 installs update to this build automatically within about six
hours, when BandPeek is quit and reopened, or via **Settings ▸ Updates**.
